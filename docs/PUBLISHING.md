# 公开发布检查

当前工作树不包含默认管理员账号或密码。部署时必须在不提交到 Git 的 `.env` 中填写 `APP_ADMIN_USERNAME` 和 `APP_ADMIN_PASSWORD`。模型和语音凭证同样只在服务端私密环境中设置。

公开发布前仍需完成以下人工确认：

1. 由代码权利人确认本项目原创部分可以使用 MIT 许可对外授权；不能仅凭技术扫描判断代码权属。
2. 只发布经过审查的干净 Git 历史，检查提交作者元数据，避免把不属于公开项目的历史和邮箱一并推送。
3. 确认第三方 DeerFlow 归档来自公开源码，并随包保留其 MIT 许可；本项目的非商业许可不能撤销上游已有的 MIT 权利。
4. 发布前再次扫描拟提交文件及其完整 Git 历史，检查凭证、私有地址和新增的内部代码；不要把 `.env`、`.runtime` 或其他本地私密文件加入 Git。

通过上述确认后，再发布源代码。本项目的 MIT 许可属于 OSI 认可的开源许可。
