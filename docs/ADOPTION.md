# 迁移与扩展路线

1. 以此仓库新建应用，决定单用户还是多用户，并先实现 server-side identity resolver。
2. 定义业务工具、工具授权 provider、run 有效期和可访问数据边界，再将工具注册到 DeerFlow 配置。
3. 明确哪些内容是权威业务数据，哪些只是 Wiki 投影或历史语境。为自动记忆编写来源、过期、撤销与冲突处理。
4. 选择上传式语音或实时流式语音。实时语音需另外接入前端采集、增量 ASR、VAD、打断、TTS 播放及授权会话。
5. 按 `local` 或 `external` 组合 Compose；部署到非本机前接入 HTTPS、正式认证、密钥管理、备份和观测。

当前仓库是可运行的通用起点，具体应用仍需自行接入业务规则和授权。
